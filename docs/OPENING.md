# 开场动画

## 2026-09-14 更新

按用户最新要求，开场改用用户自有的“镜界 MirrorSphere”V3 品牌，采用原稿钴蓝与青蓝图标、冷白背景。正文仍是原有个人项目档案，不扩大修改为全站更名。

- 0.16–0.94 秒：中轴落笔。
- 0.62–1.72 秒：左右镜像线条同步描绘。
- 1.09–2.50 秒：左右外圈自上而下画出。
- 1.87–3.33 秒：后侧短轨道与前侧倾斜长轨道逐渐闭合。
- 2.55–3.59 秒：品牌文字出现，恢复原稿全部抗锯齿边缘。
- 3.59–4.26 秒：完整品牌停留；背景三维场景已提前启动。
- 4.26–5.20 秒：品牌退场、左右展开进入项目档案。

## 原稿与实现

来源：`C:/Users/moan/Desktop/项目/基于 Unity 3D 的工业机器人数字孪生系统/品牌设计/MirrorSphere_icon_cobalt-cyan_v3.png`。

网站内副本：`public/brand/mirrorsphere-v3.png`，与原文件 SHA-256 一致，未修改原图。V3 PDF 经检查为整页位图，没有可提取的矢量路径。以 SVG 描边遮罩逐步显示原始 PNG，不用近似重绘替换标志。深色模式仅做显示亮度适配；完成阶段显示全部原稿像素。

首页在当前标签页会话首次访问时自动播放。刷新、返回首页与直接打开详情链接不会强制重播。页脚“重播开场”可重复观看。

跳过按钮、Enter、Esc 均立即进入档案；播放中背景不可操作，结束释放滚动并恢复焦点。系统或站内开启减少动态效果时，不自动播放；手动重播显示静态标题，点击进入。

## 修改位置

- `src/components/OpeningSequence.jsx`：文案、会话标记、完成时长与交互。
- `src/components/MirrorSphereMark.jsx`：原稿引用与 7 条描绘遮罩路径，包含图片失败时的文字降级。
- `src/opening.css`：独立样式、单次动画时间线、移动端和静态模式。
- `src/App.jsx`：首次播放条件、重播入口和三维场景衔接。

总时长由组件中的 `DURATION` 统一传入 CSS 变量。修改时长时，需同步检查场景预热计时与实际展开节点。项目数量、影像数量从已有项目数据自动读取。

仅新增一张用户品牌 PNG，无新依赖、声音、视频、闪屏或无限循环动画。减少动态效果下直接显示完整图标与品牌名称；图标加载失败也不会阻塞进入网站。
