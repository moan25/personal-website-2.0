# 开场动画

## 2026-09-14 更新

开场采用现有 FIELDNOTES 品牌与灰白、墨绿、铜色主题。参考 RhineLabUI 的定位线、几何标记与分阶段进入节奏，独立实现图形和排版，未使用其品牌标志、视频、字体或三维资源。

- 0–1.4 秒：扫描定位、三层档案标记聚合。
- 1.4–2.5 秒：FIELD / NOTES 错位大字逐行揭示。
- 2.5–3.4 秒：标题停留，同时预先启动背后的三维场景。
- 3.4–4.4 秒：左右展开，进入项目档案。

首页在当前标签页会话首次访问时自动播放。刷新、返回首页与直接打开详情链接不会强制重播。页脚“重播开场”可重复观看。

跳过按钮、Enter、Esc 均立即进入档案；播放中背景不可操作，结束释放滚动并恢复焦点。系统或站内开启减少动态效果时，不自动播放；手动重播显示静态标题，点击进入。

## 修改位置

- `src/components/OpeningSequence.jsx`：文案、SVG 档案标记、会话标记、完成时长与交互。
- `src/opening.css`：独立样式、单次动画时间线、移动端和静态模式。
- `src/App.jsx`：首次播放条件、重播入口和三维场景衔接。

总时长由组件中的 `DURATION` 统一传入 CSS 变量。修改时长时，需同步检查场景预热计时与实际展开节点。项目数量、影像数量从已有项目数据自动读取。

无新增依赖、视频或图片下载，无声音、闪屏或无限循环动画。
