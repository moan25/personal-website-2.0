# RhineLabUI 适配说明

检查范围：README、LICENSE、package.json、Vite 配置、数据模型、main.ts 导航、motion.ts、archive-loop.ts、详情与响应式说明，并实际打开线上演示，执行读取档案交互。参考仓库：https://github.com/LBEILC/RhineLabUI ，演示：https://rhine-lab-ui.vercel.app/ 。

原参考使用 TypeScript、Three.js、Vite 与 rolling-number；以单页面状态管理档案总览、详情和模态窗口。其构建另处理模型哈希、字体、文档导出和 PWA。本实现是独立 React + Vite 静态网站，保留 MIT 运动数学模块并重建几何与内容交互，未执行原仓库的 postinstall、字体或模型脚本。

| 参考机制 | 2.0 的个人化实现 |
| --- | --- |
| 浅色档案阵列与波浪 | 原创 Three.js 影像载体，选择后有限时长波动，空闲停止绘制 |
| 左右分列、上下切档、循环选取 | 项目为列、真实影像为行，各项目保存最后影像位置 |
| 抽取档案与镜头特写 | 档案抬升、镜头转向，左侧真实媒体、右侧项目正文 |
| 概述、研究记录、访问日志 | 项目概述、系统设计、验证范围，不模拟企业权限或真实审计日志 |
| 档案检索与收藏 | 项目关键词与分类检索，本设备收藏 |
| 全屏模型查看与装配拆解 | 使用高清图片灯箱、视频全屏和档案视角旋转替代，没有伪造硬件模型或部件装配 |
| 导出、设置、重播 | UTF-8 项目简介、主题、减少动态效果、全屏、可跳过及重播的个人品牌开场 |

刻意未搬用：Rhine/Rhine Lab 品牌、游戏世界观、原版标志、PV 音效、GLB/Blender 模型、商业字体、角色美术。当前开场复用原版三份轨迹模块，接入用户原始镜界 MirrorSphere 图标；权限及状态文本仅为视觉叙事，不是登录验证。字体采用设备系统字体，没有额外字体下载。阶段映射、改动边界和完整来源见 OPENING.md。

MIT 代码原始版权声明保留于 `src/vendor/rhinelab/LICENSE` 与 `public/licenses/RhineLabUI-MIT.txt`。首页三维几何为通用信息载体；开场扫描圆环复用原版数学轨迹，不使用其品牌物体或模型。

夸克下载地址未使用：当前访问未成功，且其中源码以外资源没有可确认的单独授权。该来源不是构建依赖。
